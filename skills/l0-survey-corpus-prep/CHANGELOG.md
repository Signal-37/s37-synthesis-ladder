## First edition

Turns open-text survey exports into corpus files the synthesis ladder can cite row by row: every row by default, a logged fixed sample when asked, or saturation sampling under a stopping rule declared before the first round. Citations, ledger counts and row placements are audited against the reads the agent actually made.

It needs the synthesis ladder edition that carries the L1 Survey Variant and the L2 Survey independence rule. It has been run end to end on synthetic exports; it has not yet been run on a live survey.

Expected lifetime: unknown.
